# Судзуко Каёко — Tokyo Life

Первый браузерный прототип открытого 3D-мира.

## Запуск
1. Распакуйте архив.
2. Откройте папку через локальный веб-сервер (например, VS Code Live Server).
3. Откройте `index.html` в современном браузере.

Three.js загружается с CDN, поэтому при запуске нужен интернет.

## Управление
- Компьютер: WASD или стрелки — движение, E — взаимодействие.
- Телефон: виртуальный джойстик слева, кнопка E справа.

## Уже есть
- Небольшой 3D-город с академией, кафе, магазином и парком.
- Простая временная 3D-модель Каёко.
- Поиск кошек и точек для фотографий.
- Монеты и сохранение прогресса в браузере.

Это стартовая версия. Модель героини, здания, анимации и карта пока являются простыми прототипами.
